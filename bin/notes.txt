1. (Variable Type)
---------------------------------------------------------------------------------------------------------------------------------
|   Variable Type   |   What it does                                                     |   Is it Nullable by default?          |
| ----------------- | ------------------------------------------------------------------ | ------------------------------------- |
| String            | Stores text values and sequences of characters.                    | No (Needs ? to accept null)           |
| int               | Stores whole numbers without fractions.                            | No (Needs ? to accept null)           |
| double            | Stores numbers with decimal points and fractions.                  | No (Needs ? to accept null)           |
| bool              | Stores true or false Boolean values.                               | No (Needs ? to accept null)           |
| List              | Stores an ordered collection (array) of items.                     | No (Needs ? to accept null)           |
| Map               | Stores data in key-value pairs.                                    | No (Needs ? to accept null)           |
| dynamic           | Can hold any type of data and its type can change at runtime.      | Yes (Accepts null automatically)      |
| var               | Automatically infers the type from the initial value and locks it. | Depends on the initial value assigned |
----------------------------------------------------------------------------------------------------------------------------------
2.(Arithmetic Operator)
----------------------------------------------------------------------------------------------------------
|   Operator   |   What it does                                |   Example (a = 10, b = 3)   |    Result  |
| ------------ | --------------------------------------------- | --------------------------- | ---------- |
| \+           | Adds values together.                         | a + b                       | 13         |
| \-           | Subtracts the right operand from the left.    | a - b                       | 7          |
| *            | Multiplies values.                            | a * b                       | 30         |
| /            | Divides values (returns a decimal/double).    | a / b                       | 3.3333     |
| ~/           | Integer division (returns whole number only). | a ~/ b                      | 3          |
| %            | Modulus (returns the remainder of division).  | a % b                       | 1          |
-----------------------------------------------------------------------------------------------------------

3.(Comparison Operators)
------------------------------------------------------------------------------------------------
|   Operator   |   What it does                      |   Example (x = 5, y = 10)   |   Result   |
| ------------ | ----------------------------------- | --------------------------- | ---------- |
| ==           | Checks if two values are equal.     | x == y                      | false      |
| !=           | Checks if two values are NOT equal. | x != y                      | true       |
| \>           | Greater than.                       | x > y                       | false      |
| <            | Less than.                          | x < y                       | true       |
| >=           | Greater than or equal to.           | x >= 5                      | true       |
| <=           | Less than or equal to.              | y <= 10                     | true       |
-------------------------------------------------------------------------------------------------

4.(Logical Operators)
-----------------------------------------------------------------------------------------------------------
|   Operator   |   Name   |   What it does                                   |   Example                   |
| ------------ | -------- | ------------------------------------------------ | --------------------------- |
| &&           | AND      | Returns true if both conditions are true.        | (5 > 3) && (10 > 5) -> true |
| ||           | OR       | Returns true if at least one condition is true.  | (5 > 3)  (10 < 5) -> true   |
| !            | NOT      | Reverses the boolean state (true becomes false). | !(5 > 3) -> false           |
------------------------------------------------------------------------------------------------------------
